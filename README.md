# AJM : ข้อมูลรถ และคนขับ (ฉบับดูอย่างเดียว)

เว็บนี้เป็นสำเนาแบบดูอย่างเดียวของหน้า "AJM : ข้อมูลรถ และคนขับ" ของบริษัท อัจจิมาเอ็กซ์เพรส ทรานสปอร์เตชั่น จำกัด

- เนื้อหาทั้งหน้าถูกเข้ารหัสไว้ เปิดดูได้เฉพาะผู้ที่มีรหัสผ่าน
- ไฟล์ `index.html` ถูกสร้างใหม่อัตโนมัติเมื่อข้อมูลต้นฉบับเปลี่ยน กรุณาอย่าแก้ไฟล์นี้ด้วยมือ
